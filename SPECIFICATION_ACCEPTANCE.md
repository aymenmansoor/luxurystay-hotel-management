# Original specification acceptance matrix

IDs use the original specification section and source line. List items and standalone prose paragraphs receive separate rows. Headings, separators and lead-ins ending in a colon are excluded. Repeated requirements remain traceable and each occurrence has equal weight.

Mapped rows have an individual status from this pass. Section-only rows preserve the original requirement with a relevant source reference. Their Partial status refers to incomplete acceptance and does not imply that the individual feature exists. Section-only rows receive zero credit. Some assertions exercise the backing API without covering every UI boundary.

Not applicable is excluded. These are evidence scores for the indexed text, with a different denominator from the previous 69.7% rubric.
